# SukimaCanvas

SukimaCanvas「隙间绘板」是[WBO](https://github.com/lovasoa/whitebophir)的分支，在原项目的基础上增加了账号系统、预约系统、外部网站接入能力等，可在东方 Project 线下集会中充当“线上签绘墙”。

你可以通过两种方式使用本项目：
1. 前往[实例网站](https://sc.numlab.org)
	1. 直接为你的活动进行预约，或者
	2. 在你的网站中适配 SukimaCanvas 的接口
2. 自部署 SukimaCanvas
