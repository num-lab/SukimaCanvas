# Send notices through a portable SMTP vendor

SukimaCanvas will deliver account and lifecycle notices by authenticated SMTP submission over implicit TLS, configured per deployment rather than compiled in. Cloudflare Email Service is the selected vendor for the first release and supplies the defaults (`smtp.mx.cloudflare.net:465`, username `api_token`, password an API token carrying Email Sending: Edit), but the adapter holds no vendor-specific code, so replacing the vendor is a configuration change. SMTP is chosen over Cloudflare's REST API for exactly that portability: the first release operates in mainland China, where deliverability to domestic mailbox providers and reachability of an overseas endpoint are the least certain parts of the design, and the sending vendor is therefore the component most likely to be replaced. A deployment that has not configured a vendor keeps the file outbox, and a deployment that configures SMTP incompletely refuses to start rather than accepting registrations whose verification mail can never arrive.
